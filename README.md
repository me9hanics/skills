# skills
AI skills, hooks, and whatnot

I also highly recommend using Matt Pocock's [skills](https://github.com/mattpocock/skills). You can see a video on his [skills pipeline](https://www.youtube.com/watch?v=M6mYodf0dJM), updated with [/wayfinder](https://www.youtube.com/watch?v=F3lL98Pj90o).


One skill that you should definitely modify for your own use is: /communication-barrier-breaker. This is also inspired by Matt Pocock's discussion on communication barriers, which are systemic drifts and one shall work to reduce this gap.
"Keep that in mind - what does the agent not know about me, or what I want? ... have to improve and get over that barrier - we often don't know what we want, our internal values and priorities are not clear, and agent doesn't know what we care about. We care about complicated things in complicated orders."
